# 在线编辑器与作品运行端

## 基准与约束

2026-10-08 基于 2d712da 重构。旧产品使用普通脚本、全局项目状态、IndexedDB 素材和本机草稿；Cloudflare KV 存放发布配置及媒体。保留旧脚本与 legacy.html 供恢复，正式入口使用独立模块。原始项目快照不修改。用户随后授权接入自有域名，已部署新版编辑器和运行端，现有线上剧情配置保持不变。

## 目标与顺序

1. 带 schemaVersion 的毫秒模型、校验和旧项目迁移。
2. 无 DOM 依赖的播放核心：视频内多事件、普通速度区间、暂停、条件、结果、跳转。
3. 编辑器与轻量播放器共用核心和视图；剧情图、时间轴、素材、撤销与恢复。
4. 私有云端草稿、不可变发布版本、冲突检查；本地文件适配器与 Cloudflare Durable Object 串行写入。
5. 模型、播放、存储及浏览器端到端验证。

## 时间与事件约定

时间为整数毫秒。场景时间 0 对应主视频入点；源时间=入点+场景时间。区间均为左闭右开，末尾选择可在恰好 duration 时触发。正常播放按视频时钟；播放器暂停/缓冲时真实倒计时也停止。图片序列使用单调时钟。慢放改变视频时间推进，不改变现实倒计时。

编辑定位只绘制，不执行事件。开始调试时跳过起点之前的事件。运行端跳转到同场景时间时不执行跨过的事件，前向跳转保留已经处理的事件，后向显式重试重新激活目标之后的事件，不自动回滚变量。每次进入新场景重新建立事件状态。条件不执行脚本，动作仅限受校验的 set/add。

选择/QTE 同时只能有一个活动事件。字幕、音频、黑边、速度效果可并行。成功结果由独立 target（continue/seek/scene/end）和 timing（immediate/sceneEnd）表达。死亡/结局仍是可编辑场景。

## 发布与数据安全

云端草稿写入需要发布授权。发布锁定副本、校验素材，再切换最新指针；历史版本只新增。回退不修改草稿。播放器一次会话固定版本。服务端使用 Durable Object 序列化版本判断及提交；旧 KV 服务继续读取旧作品及已上传的素材。新服务未部署时，本机草稿、导入导出、预览仍可使用，不能宣称已云端保存。
