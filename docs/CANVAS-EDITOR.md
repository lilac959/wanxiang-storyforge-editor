# 总画布与场景编辑改造（2026-10-08）

## 已确认的产品方向

创作者先在总画布新建、复制、删除、连接场景卡片，再双击进入场景时间轴；返回后保留画布位置和场景编辑位置。界面参考 Coze 工作流的浅色工作台、点阵画布、白色节点、紫色强调；不引入 Coze 服务。常驻提示精简，低频操作收在菜单与折叠区。

## 实施结构

- `story-board.mjs`：画布显示、选择、拖动、框选、缩放、小地图、出口拖线。
- `graph-commands.mjs`：批量复制 / 删除，稳定 ID 更新，引用处理。
- `timeline.mjs`：旧画面兼容、多片段、分割、排序、移动、关联内容和删除空位。
- `model.mjs`：schemaVersion 3；旧 v1 / v2 自动兼容，原始备份保留；时间、素材与出口校验。
- `player-view.mjs`：在场景时钟上切换片段，映射原素材时间；草稿预览和公开运行端共享实现。
- `projects.mjs`：作品独立固定链接、版本恢复、可恢复云端归档；已有默认作品入口保留。

## 创作操作

1. 顶部作品名旁的品牌按钮打开“我的作品”；可新建、复制、导入、打开本机或云端作品。
2. 总画布新建场景；单击选择，双击进入编辑。Shift 框选，Ctrl/⌘ + 滚轮缩放。
3. 片段可从素材库添加或拖入画面 / 时间轴。画面主轨同一时刻仅允许一个片段。
4. 分割使用当前播放头；前移 / 后移调整顺序；移动到空位形成黑场。
5. 字幕、互动、声音和图片叠加可以关联画面片段；移动或排序时跟随。
6. 删除片段可以保留空位或前移后续内容；关联内容单独确认。
7. 返回画布后互动自动成为出口；拖动出口至目标场景，或打开出口选择目标。
8. 删除场景留下“待连接”出口；发布前必须连接或明确设置继续 / 结束。
9. “更多”菜单包含保存、导入、导出、版本、检查、帮助。
10. 预览中可切换桌面、竖屏、横屏，不重建播放会话。

## 边界

- 视频之间使用浏览器切换素材，会有加载间隔；不承诺帧精确或无缝剪辑。
- 裁剪后超出场景范围的字幕 / 互动会被校验阻止发布，需要作者调整。
- 本机项目回收站与云端作品归档是不同存储位置；归档草稿不取消已发布链接。
- 图片叠加使用静态位置与尺寸；未加入关键帧、转场、多层视频合成、转码或实时协作。
- 编辑器优先桌面；手机用于运行端与预览，实际 iOS Safari 仍需要真机验收。

## 旧作品与手机开屏

旧项目保留经典样式；新项目默认简洁样式。加载和开屏视频根据素材比例完整显示，标题及进度绑定画面区域，手机竖屏留黑、横屏放大。普通玩家看不到开场资源条目计数。慢放保留任意区间设置，没有新增片尾快捷慢放。
