# 创作者使用说明

## 三层关系

**作品**是一整个可分享的互动故事。**剧情段落**是故事中的一段，可以是一段完整视频，也可以是一组依次播放的图片。**段落里的内容**包括互动、字幕、声音、慢放和黑边，在时间轴中安排。

例如作品“密室逃脱”中有“进入房间”“开门成功”“失败结局”。在“进入房间”的同一段视频第 3 秒出现找钥匙热点，第 8 秒出现开门选择，不用为了每次互动拆视频。

## 打开与迁移

1. 编辑器优先恢复本机新版草稿，没有时尝试旧草稿、已发布作品，最后才使用制作示例。
2. 点击“导入”，选择整个项目 ZIP。导入内容成为独立草稿，原项目和当前草稿会进入本机恢复列表。
3. “作品与恢复”可以打开云端草稿、本机备份或制作示例。
4. 旧片尾慢放换算为普通速度区间，原素材不修改。旧作品的待配置节点仍需处理后才能发布。

## 制作完整故事

1. 新建剧情段落，起一个容易识别的名字。
2. 导入视频或多张图片。视频可设原文件入点、出点；图片可改展示时长、复制、插入、替换和移动顺序。
3. 拖动画面定位条到想放互动的位置，点“＋ 操作”“＋ 选择”或“＋ 热点”。
4. 选中时间轴互动，在右侧设置开始位置、可用时间、操作方式和成功/失败后去哪。
5. 添加“慢放区间”，分别设置开始、结束、倍速，可以在视频任何位置。
6. 同样添加字幕、音频、电影黑边。拖片段移动，拖两端改变范围，选中后方向键微调 0.1 秒。
7. 在“剧情地图”从出口连接到目标段落，也可在右侧直接选择去向。
8. 把真正的第一段设为作品入口。地图和列表排列不决定入口。

## 互动时间

| 设置           | 玩家看到什么                   | 用途           |
| -------------- | ------------------------------ | -------------- |
| 等待玩家       | 直到完成，没有倒计时           | 从容选择剧情   |
| 操作倒计时     | 固定现实时间，慢放不会延长秒数 | 限时操作       |
| 视频播放区间   | 视频走到区间末尾时结束         | 视频中途操作   |
| 互动时暂停画面 | 视频停住，玩家仍可操作         | 看清画面后选择 |

同时只允许一个需要玩家操作的互动。字幕、音频和效果可以同时出现。按视频位置结束的互动不能同时暂停画面。

成功后可以立即执行结果，也可以让当前段落播完再进入下一段。结果可以继续、跳到当前视频指定位置、进入另一段或结束作品。“成功后结束当前慢放”仅影响当时的慢放区间。

## 预览与正式播放

- 拖动定位条只看画面，不执行剧情动作。
- “预览当前”从当前段落开始；时间轴播放按钮从当前位置开始；“试玩作品”包含加载页与开屏。
- 暂停、后台切换、视频缓冲会停止互动倒计时。
- 重新开始清空本轮变量。跳回当前视频早先位置会重新允许之后的互动，但不会自动撤销已得到的分数。
- 浏览器若阻止自动播放，点击提示继续。返回开屏可重启完整体验。

## 保存、发布与回退

编辑后自动保存本机。连接创作者授权后，合法配置自动同步私有草稿，草稿修改不会改变玩家版本。

1. 点击“发布作品”，处理检查列表中的错误。提醒项自行判断。
2. 确认发布，等待素材检查和上传。原文件按块上传，不缩短或转码。
3. 成功后获得本次版本固定链接及当前发布版链接。
4. “版本”可恢复历史发布版；回退不覆盖编辑中的草稿。
5. 其他设备修改产生冲突时，先导出自己的草稿，再打开云端副本比较，系统不会静默覆盖。

“导出”包含配置和素材库原文件，适合长期备份。清理浏览器站点数据会移除本机草稿及未上传素材，请保留 ZIP 备份。

## 素材库与时间轴（2026-10-09）

- 素材库按全部、视频、图片、音频、互动 UI 分类，支持搜索、排序和点击预览。素材菜单可重命名、查看使用位置、替换或移除未使用的素材。
- 场景编辑时，左侧素材可以直接拖到时间轴。视频进入主画面轨道；图片拖到叠加轨道作为叠加，其余位置作为主画面；音频和互动 UI 分别进入对应轨道。
- 主画面拖入已有片段内时，吸附到最近的片段边界并向后推移内容，不覆盖原片段。拖动已有主画面到占用位置会调整顺序；拖到空位则保留空位。带有片段关联的互动、字幕或声音会随片段移动。
- 拖动片段中间移动，拖动左右两端裁剪；视频裁剪不会超出原素材。靠近边界或播放头时自动吸附，按住 Alt 可暂时关闭吸附。撤销、重做也可在场景编辑顶部使用。
- 互动 UI 是可复用的代码组件。素材库可切换电脑、手机竖屏、手机横屏预览，实际操作并查看成功、失败和声音效果。选中时间轴上的互动后，可更换兼容的互动 UI，原来的剧情去向保留。
- 当前内置金框选项、简洁选项、长按、点击、连点、滑动和热点。用户提供的图片、视频或 PNG 动画参考可作为后续定制组件的参考素材；上传普通图片不会自动变成完整互动组件。
- 同一时段只能有一个需要操作的互动，拖入占用时段时会提示选择空位。
- 通用操作集中在右上角 ☰；画布卡片旁提供编辑和从此处试玩。死亡、返回开屏等连线以可定位的去向标签简化，点击“全部连线”可查看完整连接。

## 导航与作品管理（2026-10-09）

- 顶部作品名称只展示；重命名从左下角“作品”进入，在作品卡片的“···”菜单操作。
- 顶部保留“保存”“完整试玩”“发布”。自动保存继续生效，也可点击保存或按 Ctrl+S。保存提示会区分本机保存和云端同步。
- 通用菜单 ☰ 位于顶部右上角，紧邻保存按钮左侧；包含导入作品、导出备份、检查作品、发布历史、帮助与快捷键。
- 左侧保留画布、素材、设置，底部固定作品入口。剧情变量在设置里；连接发布服务从发布进入，连接成功后继续发布前检查。
- 我的作品展示封面、名称、最近编辑时间、保存位置和当前编辑标记。同一个作品的本机及云端记录合并展示，不覆盖任何版本。
- 作品卡片菜单支持重命名、复制、移入回收站；回收站可以恢复。打开不同版本时可选择继续本机版本或打开云端版本，原内容保留为恢复副本。
- 关闭作品列表会回到原编辑位置。首次打开且尚未缓存的云端作品使用占位封面，打开后可显示本机素材封面。

- 设置页不再显示重复的返回画布按钮，直接使用左侧画布入口；场景编辑的返回画布按钮保留。

## 统一卡片用途（2026-10-09）

- 卡片用途包括剧情、加载、开屏、结局、失败。加载和开屏可以双击进入共用编辑器，使用素材库、画面预览和时间轴。
- 加载、开屏各最多一张，可以删除。替换相同用途会先提示，原卡片变回剧情，素材和互动保留；开场用途下原互动暂不执行。
- 加载等待实际资源就绪和最少展示时间；开屏循环或停留最后一帧，点击开始按钮或按键后才进入剧情。
- 标题、副标题、进度、开始按钮分轨展示，可移动和裁剪出现区间，也可设置文字、位置、大小、颜色，并在预览中拖动位置。
- 删除加载后使用默认资源准备界面；删除开屏后进入起始剧情。开屏的目标同时作为起始剧情。复制开场卡片得到普通剧情卡片。
- 旧作品自动转换，保留内容与位置。复制、删除在卡片菜单中；多选操作在选中卡片附近。画布左上角保留搜索与新建卡片。

## 检查作品与自动修复

在顶部通用菜单选择「检查作品」，或点击「发布」进入同一套检查。

系统先读取缺失的素材时长/尺寸并补齐缺失的内容编号；自动修复前保留本机恢复副本。展开「自动修复记录」可查看变化，并立即撤销。修复后已发生其他编辑时，通过顶部撤销逐步恢复，或在作品恢复中打开修复前副本。

需要创作判断的问题按卡片列出：截取时间、主画面重叠、互动冲突、素材替换和剧情去向均由你决定。点击问题按钮可进入对应卡片、选中时间轴内容并标出字段；连接问题会定位卡片和对应出口。

备用卡片未接入主流程会提醒；正式剧情中没有画面或待连接的出口需要发布前处理。系统不自动删除内容、移动互动或选择后续剧情。

## 互动 UI 与卡片目录

「卡片目录」用于展开/收起左侧卡片列表。选中卡片后的属性浮层不会改变画布位置。

原版经典金框、长按、点击、连点、四个滑动方向与热点在素材库的「互动 UI」分类中，可预览、试用并添加到时间轴。新版简洁互动样式已移除，原有配置兼容转换为经典样式。

## 多轨叠加时间轴（2026-10-09）

- 主画面顺序播放；插入素材时后续主画面顺延。拖到主画面上方的“＋ 叠加”区域，可让图片或视频与主画面同时出现。
- 重叠素材分到独立轨道，不覆盖或删除原素材。没有时间重叠的同类内容可以共用轨道；轨道顺序保存到作品，重新打开保持不变。
- 图片、叠加视频、字幕共用画面层次：上方轨道显示在前面。轨道左侧悬停显示上移、下移、临时隐藏和拖动锁定。
- 音频允许重叠并混合播放，分别调整音量。叠加视频保留原声，右侧可调整原声音量或设为 0。
- 隐藏和静音只作用于本次编辑预览与试玩，不影响发布，也不改变剧情时间。拖动锁定是临时编辑状态，刷新后重置。
- 互动选项的一组按钮作为一个互动片段。两组独立互动同时等待输入时标记冲突范围；作品检查可分别定位双方，系统不会自动调整它们的时间。
- 主画面片段移到叠加轨道时保留素材截取范围；原先跟随它的内容同步移动，并转为独立内容。可以撤销整个操作。
# 时间轴播放与定位

- 画面下方“播放/暂停”只播放当前卡片的画面、音频和 UI 出现时间；不需要完成互动，也不跳转到其他卡片。空格可切换播放，输入文字时不会触发。
- “试玩场景”和“完整试玩”用于实际操作互动。未完成的其他卡片不会提前阻止试玩；只有走到未连接出口或遇到素材错误时，才提示具体原因并提供“返回编辑并定位”。正式发布仍执行完整检查。
- 拖动时间轴顶部播放头手柄，或按住时间刻度、轨道空白处拖动，可连续查看画面。左右方向键逐帧定位，默认每帧 1/30 秒；Home / End 跳到时间轴首尾。
- 拖动片段中间移动，拖动两侧裁剪；拖动时显示时间和时长。右键提供分割、复制、删除、对齐播放头和提到叠加轨道。无法使用的操作置灰。
- “吸附”帮助对齐播放头、其他片段边缘及时间标记。可关闭，或按 Alt 临时自由拖动；播放头始终自由移动。
- Ctrl + 滚轮以鼠标位置缩放，Shift + 滚轮横向浏览，普通滚轮上下浏览轨道。“显示全部”恢复完整时间轴。
- “添加标记”给当前时间命名；点击金色标记可定位、修改名称或删除。标记仅用于编辑，不显示在玩家画面。
- 主轨磁吸关闭时，删除主画面默认保留空隙和关联内容；打开后主画面编辑会消除空隙。关联内容是否一起删除由勾选决定，所有编辑操作支持撤销。
- 作品卡片的“更多操作”包含重命名、复制作品、移入回收站。

## 画面元素拖动与拉伸

- 在画面里选中互动 UI 或字幕，显示四角和四边共八个控制点；拖动框内移动位置。分支按钮可分别选中调整。
- 互动 UI 四角等比例缩放，四边分别横向或纵向拉伸。右侧“提示大小”“横向拉伸”“纵向拉伸”同步显示；热点实际点击范围随尺寸变化。
- 字幕四角同时调整字号与文本框，左右边调整换行宽度，上下边调整文本区域高度，文字比例保持正常。文本框宽高留空时恢复自动大小。
- 拖动到画面中心附近会显示吸附线；关闭“吸附”或按住 Alt 可自由移动。一次拖动对应一次撤销，Esc 取消当前拖动，锁定的轨道禁止调整。
- 控制点不随元素缩小，小于 44 像素的元素显示可抓取的控制框。尺寸以作品画面保存，桌面和手机预览共用；试玩中不显示编辑控制点。
- 选框使用白色细线、圆形角点和短条边点；点击画面或时间轴空白处取消选中，点击其他元素切换选中。修改右侧属性时保留选框；未拖动时 Esc 取消选中。

## 加载与慢放

- 完整试玩先显示加载封面；加载背景视频完整下载、首帧可显示后切换到视频。作品实际引用的图片、视频、音频和互动图标全部下载并检查完成后，进度到 100%，再按加载节点连接进入开屏；素材库中未使用的资源不下载。
- 已完成的下载存入浏览器缓存，重试或再次打开可复用；下载失败保留加载画面并显示具体素材和重试入口。首次打开需要先取得作品配置才能确定加载封面，再次打开可立即显示此前缓存的封面。
- 编辑区播放头跟随视频实际时间，避免慢放时重复跳时间；连续同源片段切换速度时复用视频。当前变速不生成中间帧，低帧率素材在低倍速下仍可能有逐帧感；剪映的光流补帧属于另一个处理流程。

## 时间轴快捷键（2026-10-10）

在场景时间轴中使用以下按键。输入框、属性面板和弹窗内不触发时间轴快捷键；锁定轨道不能修改。空格播放或暂停。

| 操作 | 快捷键 |
| --- | --- |
| 删除选中片段 | Backspace |
| 分割选中片段 | C |
| 批量分割 | Ctrl + Shift + B |
| 向右裁剪 | W |
| 选择工具 | A |
| 向左／向右全选 | [ / ] |
| 主轨磁吸开关 | P |
| 吸附开关 | N |
| 联动开关 | ~ |
| 放大／缩小时间轴 | + / - |
| 显示完整时间轴 | Shift + Z |
| 上一帧／下一帧 | ← / → |
| 跳到首帧／尾帧 | Home / End |
| 添加标记 | M |
| 分离／还原音频 | Ctrl + Shift + S |
| 启用／停用片段 | B |
| 撤销／重做 | Ctrl + Z / Ctrl + Shift + Z |
| 复制／剪切／粘贴 | Ctrl + C / X / V |
| 复制／粘贴属性 | Ctrl + Shift + C / V |

- C 分割选中片段，批量分割处理播放头经过的所有未锁定片段；分割两侧各需至少 0.1 秒。W 保留播放头左侧，裁掉选中片段右侧。
- 左右全选以播放头为界，跨过播放头的片段也会选中；锁定轨道不参与。
- 主轨磁吸关闭时保留空隙，开启后编辑主画面会将主画面依次排紧。联动决定关联字幕、互动和音频是否跟随主片段移动及变速；两个开关保存到场景。
- 停用保留片段和时间占位，时间轴显示为灰色，预览与正式试玩跳过其内容；还原音频仅移除对应的分离音轨并恢复视频原声。
- 属性只能粘贴到相同类型的片段，不覆盖素材、文字内容、编号和剧情去向；粘贴速度属性会同步调整时长。编辑操作支持撤销。

## 互动 UI 关键帧（2026-10-11）

- 选中互动片段，右侧外观中“位置”“大小”“横向拉伸”“纵向拉伸”各有菱形按钮。位置同时记录横纵坐标；分支选项可分别设置。
- 在播放头位置点击空心菱形添加第一帧。该属性有关键帧后，移动播放头并拖动画面元素或修改数值，自动新增关键帧；在已有帧位置修改则更新该帧。没有关键帧的属性仍修改整段的静态值。
- 实心菱形删除当前帧；左右箭头跳到上一帧或下一帧。属性旁的小菜单提供曲线和“清除”；“清除”移除该属性动画，保留当前显示值。只有播放头位于互动区间内时才能添加关键帧。
- 选中互动后，互动片段内部显示菱形关键帧，同一时刻的各属性合并为一个菱形，拖动或删除时一起操作。点击菱形定位，左右拖动调整发生时间；选中菱形按 Backspace 删除，Ctrl + Z 撤销。拖动按 Esc 取消，同一属性同一时间不能放两个关键帧。
- 两帧之间默认匀速过渡，可在起始帧选择缓入、缓出、缓入缓出，控制它到下一帧的运动。首帧之前和末帧之后保持端点值。
- 关键帧随互动片段移动和复制；裁剪保留原动画的对应部分，延长片段可恢复原有曲线。分割后两段沿用连续运动。开启联动时，关联主画面变速也会同步调整关键帧时间。
- 编辑预览和正式试玩使用同一套位置与尺寸计算，点击区域跟随显示元素。暂停、缓冲和进入等待操作时，移动也暂停；时间轴播放仍可完整预览运动。
