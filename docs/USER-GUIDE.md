# 创作者使用说明

## 三层关系

**作品**是一整个可分享的互动故事。**剧情段落**是故事中的一段，可以是一段完整视频，也可以是一组依次播放的图片。**段落里的内容**包括互动、字幕、声音、慢放和黑边，在时间轴中安排。

例如作品“密室逃脱”中有“进入房间”“开门成功”“失败结局”。在“进入房间”的同一段视频第 3 秒出现找钥匙热点，第 8 秒出现开门选择，不用为了每次互动拆视频。

## 打开与迁移

1. 编辑器优先恢复本机新版草稿，没有时尝试旧草稿、已发布作品，最后才使用制作示例。
2. 点击“导入”，选择整个项目 ZIP。导入内容成为独立草稿，原项目和当前草稿会进入本机恢复列表。
3. “作品与恢复”可以打开云端草稿、本机备份或制作示例。
4. 旧片尾慢放换算为普通速度区间，原素材不修改。旧作品的待配置节点仍需处理后才能发布。

## 制作完整故事

1. 新建剧情段落，起一个容易识别的名字。
2. 导入视频或多张图片。视频可设原文件入点、出点；图片可改展示时长、复制、插入、替换和移动顺序。
3. 拖动画面定位条到想放互动的位置，点“＋ 操作”“＋ 选择”或“＋ 热点”。
4. 选中时间轴互动，在右侧设置开始位置、可用时间、操作方式和成功/失败后去哪。
5. 添加“慢放区间”，分别设置开始、结束、倍速，可以在视频任何位置。
6. 同样添加字幕、音频、电影黑边。拖片段移动，拖两端改变范围，选中后方向键微调 0.1 秒。
7. 在“剧情地图”从出口连接到目标段落，也可在右侧直接选择去向。
8. 把真正的第一段设为作品入口。地图和列表排列不决定入口。

## 互动时间

| 设置           | 玩家看到什么                   | 用途           |
| -------------- | ------------------------------ | -------------- |
| 等待玩家       | 直到完成，没有倒计时           | 从容选择剧情   |
| 操作倒计时     | 固定现实时间，慢放不会延长秒数 | 限时操作       |
| 视频播放区间   | 视频走到区间末尾时结束         | 视频中途操作   |
| 互动时暂停画面 | 视频停住，玩家仍可操作         | 看清画面后选择 |

同时只允许一个需要玩家操作的互动。字幕、音频和效果可以同时出现。按视频位置结束的互动不能同时暂停画面。

成功后可以立即执行结果，也可以让当前段落播完再进入下一段。结果可以继续、跳到当前视频指定位置、进入另一段或结束作品。“成功后结束当前慢放”仅影响当时的慢放区间。

## 预览与正式播放

- 拖动定位条只看画面，不执行剧情动作。
- “预览当前”从当前段落开始；时间轴播放按钮从当前位置开始；“试玩作品”包含加载页与开屏。
- 暂停、后台切换、视频缓冲会停止互动倒计时。
- 重新开始清空本轮变量。跳回当前视频早先位置会重新允许之后的互动，但不会自动撤销已得到的分数。
- 浏览器若阻止自动播放，点击提示继续。返回开屏可重启完整体验。

## 保存、发布与回退

编辑后自动保存本机。连接创作者授权后，合法配置自动同步私有草稿，草稿修改不会改变玩家版本。

1. 点击“发布作品”，处理检查列表中的错误。提醒项自行判断。
2. 确认发布，等待素材检查和上传。原文件按块上传，不缩短或转码。
3. 成功后获得本次版本固定链接及当前发布版链接。
4. “版本”可恢复历史发布版；回退不覆盖编辑中的草稿。
5. 其他设备修改产生冲突时，先导出自己的草稿，再打开云端副本比较，系统不会静默覆盖。

“导出”包含配置和素材库原文件，适合长期备份。清理浏览器站点数据会移除本机草稿及未上传素材，请保留 ZIP 备份。
