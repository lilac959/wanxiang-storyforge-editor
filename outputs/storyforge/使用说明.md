# 叙境 · 互动影游编辑器

双击 index.html 即可使用。也可将整个 storyforge 目录交给任意静态网站服务器。

- 剧情编排：创建节点，选择本地视频或填写视频直链，配置触发时间。
- 拖拽导入：将电脑上的图片或视频直接拖到中间画布，或右侧对应上传区域。多张图片追加为当前节点的分镜；一个视频替换当前节点的视频。画布可同时接收一个视频与多张图片，导入后默认预览分镜。单个节点不支持一次导入多个视频。
- 加载页可拖入一张背景图，开屏页可拖入一个视频。拖入时目标区域高亮；不支持的文件会提示，不会跳转离开编辑器。
- 分镜图片：在同一个节点的「分镜图片」中批量上传多张 PNG、JPG、WebP 或 GIF。每张默认展示 3 秒，可修改时长、上移／下移或移除，最多 100 张。
- 原视频与分镜可同时保留，通过「预览素材」切换。分镜模式按各图片时长顺序播放；总时长由图片时长相加得到。点击缩略图或拖动进度条可定位画面，播放按钮可连续播放／暂停。
- 「预览当前」和「试玩作品」也会使用各节点选定的预览素材，分镜模式下仍支持交互触发与分支跳转。若交互在分镜结束前触发，画面会停留等待操作；想先看完整分镜，可将触发时间设为分镜总时长。
- 分镜图片、顺序和时长会自动保存，并随项目导入导出。此功能提供分镜动态预览，不会合成为 MP4 文件。
- 支持分支选择、限时点击 QTE、点击热点和自动衔接。热点可以点击画面定位。
- 故事地图显示每个节点的分支目的地；点击卡片返回编辑。
- 加载页面：配置封面图片、标题、加载提示、进度条颜色和最短时长。
- 加载背景已替换为提供的视频，加载期间静音循环播放，标题与真实进度条叠加显示；全部资源就绪后停止背景并进入开屏动画。加载页的「预览当前」会在完成后暂停画面供检查。上传背景图片可以切回静态背景。
- 开屏动画：配置文字或视频开屏、展示时长、跳过开关。
- 已配置提供的视频为开屏动画，持续循环播放；从开始即显示小尺寸暖金色「按任意键开始」。玩家按任意键或点击画面后进入第一个剧情节点，提示为纯文字，没有悬停效果。
- 预览当前：体验当前节点；试玩作品：从加载页开始运行完整流程。
- 试玩顺序固定为「加载页面 → 循环开屏动画 → 按任意键 → 第一个剧情节点」。加载页至少停留 3 秒；资源提前就绪则等满 3 秒，加载超过 3 秒则就绪后进入开屏，不等待背景视频结束。进度按真实加载结果推进。重新开始也从加载页起步。
- 自动保存：配置保存在 localStorage，本地视频和图片保存在 IndexedDB。请使用同一浏览器、同一地址访问。清理浏览器数据会删除保存的内容。
- 保存配置：点击顶部「保存配置」保存全部配置，并更新编辑区、节点列表和故事地图；后续试玩使用最新配置。素材正在导入时，请等待完成再保存。
- 导出项目：下载 ZIP 包，包含 `project.storyforge.json` 完整配置、`assets/` 原始图片和视频、`assets.json` 素材路径清单和使用说明。素材保留原始字节，不转码。视频直链会尝试下载并收入包内；需允许跨域访问，下载失败会提示导出失败，不会生成缺少素材的包。ZIP 最大支持 4GB，打包需要相应可用内存。
- 导入项目：可直接选择编辑器导出的 ZIP，恢复配置及原始素材；兼容旧版内嵌素材 JSON。解压后的配置与素材清单、素材文件夹应一起保留；恢复时选择完整 ZIP。

加载页面使用提供的角色封面，左下角进度为动态叠加。完整试玩会下载当前各节点选用的视频或分镜，以及开屏视频，检查图片与视频是否可解码，再进入作品。进度为各资源实际下载比例的平均值，全部解码就绪后才达到 100%；未知总大小的资源在下载完成后计入，加载失败会暂停并显示重试。浏览器内已有素材通常会很快完成。视频直链需允许跨域下载；较大的作品需要更多内存和等待时间。

此版本为可运行的前端原型，未接入账号、云存储、转码、多人协作或作品发布服务。示例山景为 CSS 绘制，不包含参考站的视频素材。建议使用浏览器支持的 MP4（H.264/AAC）或 WebM。

- 替换素材：在分镜列表点击对应图片的「替换图片」，保留其顺序、展示时长和交互配置；视频素材区点击「替换视频」，加载页和开屏页也有对应替换入口。替换完成后更新预览，并随配置保存和 ZIP 导出。

- 拖拽排序：预览下方缩略图和右侧分镜卡片均可拖拽，以高亮插入线确定位置；松手后同步更新顺序并保存，保留素材、时长和交互。左侧剧情节点也可拖拽排序，第一个节点作为试玩入口，分支跳转仍按节点 ID 保持关联。

- 预览当前与试玩作品仅让预览画面铺满当前窗口，不切换浏览器或编辑器的全屏状态；关闭预览返回编辑器。

- Chapter 01 选项一接入 1–9.mp4，选项二保持待配置。每段默认片尾最多 2 秒以 0.25 倍速慢放，按空格成功进入下一段，响应时限 8 秒；失败可点击重试当前 QTE。短片默认整段慢放，原素材不转码。每段右侧「片尾慢放 QTE」可独立修改按键、范围、倍速、失败规则，上方响应时限及成功/超时跳转同样可编辑。
